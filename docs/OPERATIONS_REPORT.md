## 3. 사이트 도입 전 대비 개선점

도입 전에는 관리자가 신청을 직접 받아 **수량·규정을 매번 손으로 확인**하고, 승인 여부를 개별 연락으로 알려야 했다. 아래는 그 업무가 시스템으로 어떻게 바뀌었는지 정리한 것이다.

### 3.1 학생 쪽

| 도입 전 | 지금 |
|---|---|
| 남은 수량을 관리자에게 물어봐야 앎 | 기간을 고르면 **가용 수량이 바로 표시**(달력에 날짜별 가용 표시) |
| 규정(시간·기간·주말·학년)을 학생이 알아서 지켜야 함 → 어기면 거절 후 재신청 | 규정 위반 신청은 **제출 단계에서 사유와 함께 차단** |
| 여러 기자재를 따로따로 요청 | **장바구니로 한 번에 신청**(평균 7.9개 품목) + 부속까지 선택 |
| 진행 상황을 직접 문의 | **신청번호·비밀번호로 상태 조회** |
| 전체 대여 현황을 알 수 없음 | **전체 대여 현황 달력** 공개(이름 마스킹) |

### 3.2 관리자 쪽

| 도입 전 | 지금 |
|---|---|
| 승인할 때마다 재고를 직접 계산 | **승인 화면에 품목별 "가용 n/m · 부족 k개" 자동 표시**, 부족하면 승인 버튼 자체가 막힘 |
| 같은 시간대 강의실 중복 예약 위험 | **승인된 예약·정규 수업 시간표와 겹치면 자동 경고·승인 차단** |
| 명단·학년 확인을 사람이 함 | **학과 명단과 자동 대조**, 학년은 명단 값으로 확정 |
| 노쇼·연체 학생을 기억에 의존 | **대여 제한자 등록 → 신청 자동 차단** |
| 수업용 대량 대여를 별도 관리 | **수동 등록 메뉴**로 규정을 넘는 대여도 시스템 안에서 기록 |
| 처리 이력·통계 없음 | **대여 이력 검색**(이름·학번·품목·기간) + 대시보드(대기·대여 중·반납 예정·대여 예정, D-Day) |
| 학과장 승인 여부를 따로 확인 | 신청서에 **학과장 승인 여부가 기록**되어 목록에 표시 |

### 3.3 데이터로 확인되는 효과

- **접수 시간 규정 준수율 100%**: 학생 기자재 신청 품목 1,079개 전부 평일 09:00~17:00 사이에 접수(주말·17시 이후 0건).
- **대여 목적 기재율 100%**: 필수 입력으로 바꾼 뒤 누락 없음.
- **재고 계산 자동화**: 기자재 1,312대/개, 부속 521개가 수작업 계산 없이 처리됐다. 승인 시 재고 확인 도입(10/02) 이후 초과 승인은 구조적으로 불가능하다.
- **재신청 원인 제거**: 거절 사유의 48%가 이제 자동 차단 유형이라, 같은 사유의 "거절 → 재신청" 왕복이 줄어든다.

> | 재고 확인에 걸린 시간 | (기입) | 0분(자동) |

### 부록: 집계 방법

- 테스트 신청과 관리자 수동 등록(메모가 "수동 등록"으로 시작)은 "학생 신청" 집계에서 제외했다.
- 시각은 모두 한국 시간(KST)으로 변환해 집계했다.
- 거절률·거절 사유는 신청(묶음) 단위, 접수 시간대는 품목 단위로 셌다.
- 기자재 순위는 승인·반납 완료된 학생 신청의 수량 합계다(수동 등록 제외).
- 조회만 했고 데이터는 변경하지 않았다.
